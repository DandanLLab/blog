## 这是什么这是**蛋蛋知识库**的 Issues 直发通道验收文：在本仓库写 issue 并打上「公开」label，Actions 每次构建会把它拉进 md/公开/issues/ 并发布到门户；关闭 issue 即自动下架。用法：手机/网页 GitHub 直接写 issue → 打 label → 一分钟后门户见。
